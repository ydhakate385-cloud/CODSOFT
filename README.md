## 🔹 Task 1: Titanic Survival Prediction

### 📌 Objective
To build a machine learning model that predicts whether a passenger survived the Titanic disaster.

### 📊 Dataset
Titanic dataset containing passenger details such as:
- Age
- Gender
- Passenger Class
- Fare
- Embarked
- Survival Status

### 🛠️ Steps Performed
- Data loading and exploration
- Data cleaning and preprocessing
- Handling missing values
- Encoding categorical variables
- Feature selection
- Model training using Machine Learning algorithms
- Model evaluation

### 🧰 Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn

### ✅ Outcome
Successfully built a model to predict passenger survival on the Titanic.
